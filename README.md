# 🧠 두뇌 배틀

수학·상식·퍼즐·두뇌·심리 **39종 미니게임**을 친구들과 겨루는 실시간 웹게임. 같은 게임이라도 **숫자와 상황이 매번 새로 만들어진다**. 라운드 1등은 상대에게 방해 카드(안개·거울·시간 단축·점수 강탈)를 쓴다.

## 두 가지 모드
| 모드 | 설명 |
|---|---|
| ⏱ **타임어택** | 게임마다 제한시간이 있다. 정답 `50 + 속도 보너스(최대 70)`, 라운드 최속 정답 +25 |
| ♾️ **무제한** | **어려운 문제**, 시간 제한 없음. 정답 100점, 첫 정답 +20. 🏳️ 포기 버튼, 방장은 ⏹ 라운드 마감 가능. 속도만 겨루는 게임(색깔 함정·틀린 하나·순서대로 터치)은 빠진다 |

대기실에서 모드, 라운드 수(8·12·16·24), 게임 종류(분류별)를 고른다. 혼자 연습도 같은 설정을 쓸 수 있다.

## 게임
| 분류 | 게임 |
|---|---|
| 수학 | 🧮 숫자 조합 · ⚡ 암산 질주 · 🔢 수열 추리 · 🍎 과일 방정식 · 🕐 시계 각도 · 🔮 마방진 · 🔺 숫자 피라미드 · ➕ 연산자 넣기 · 📝 문장제 |
| 상식 | 📏 어림 감각 · 🧠 상식 번개 · 📜 역사 줄 세우기 · 🔤 초성 퀴즈 |
| 퍼즐 | 🕵️ 범인 추리 · 🔐 금고 털기(숫자야구) · 🃏 결! 합! · 💡 불 끄기 · 🔢 미니 스도쿠 · ⬛ 노노그램 · 🔥 성냥개비 · 😇 기사와 건달 · 🦓 논리 그리드 · ⚖️ 가짜 동전 · 🗺️ 최단 경로 |
| 두뇌 | 🟦 패턴 기억 · 🎹 순서 기억 · 📟 숫자 기억 · 👀 순간 포착 · 🎨 색깔 함정 · 🔍 틀린 하나 · 🔟 순서대로 터치 |
| 심리 | 🎯 평균의 함정 · ⚖️ 소수결 · 🥷 최저 유일수 · 🗡️ 배신의 금고 · 🎴 인디언 포커 · 💰 공공재 게임 · 🔨 블라인드 경매 · ✊ 단체 가위바위보 |

- 퍼즐은 모두 **자동 생성**되고 답이 하나로 정해지는지 검사한다 (스도쿠·숫자야구·기사와 건달·논리 그리드·가짜 동전 등). 노노그램·불 끄기·연산자 넣기는 조건만 맞으면 어떤 답이든 인정한다.
- 어려움(무제한 모드)에서는 판이 커지거나 단서가 줄어든다: 4자리 숫자야구, 6×6 스도쿠, 7×7 노노그램, 5×5 불 끄기, 12개 동전(무거운지 가벼운지 모름), 4명×3범주 논리 그리드, 두 자리 성냥개비 식 등.
- 심리전은 매 라운드 조건이 바뀐다 (평균의 배율, 소수결 주제, 배신의 금고 보상, 공공재 배율, 경매 숫자 개수 등). 결합·인디언 포커·블라인드 경매처럼 더 지니어스·데블스 플랜 같은 서바이벌 예능에서 나온 규칙을 바탕으로 했다.

## 실행
```
npm start        # http://localhost:3000  (의존성 없음, Node 18+)
```
같은 와이파이의 친구는 `http://내IP:3000`으로 접속한다.

## 친구와 온라인으로 하려면 (서버 배포)
멀티플레이에는 **서버가 켜진 주소**가 필요하다 (GitHub Pages는 정적 호스팅이라 서버를 못 돌린다).
- **Railway / Render / Fly.io**: 이 저장소를 연결하면 `npm start`가 자동 실행된다. 환경변수 `PORT`만 쓴다.
- 배포된 주소를 친구에게 보내면 끝. 홈 화면에서 방을 만들고, 친구는 "열린 방"에서 누르거나 4자리 코드를 입력한다.
- 서버 없이 열면(GitHub Pages 등) **혼자 연습**만 가능하다.

## 구조
- `src/` — 게임 소스 (`gen.js`·`gen2.js` 문제 생성기와 판정, `app.js` 게임 진행·화면, `ui2.js` 새 게임 화면, `rt.js` 연결 계층, `data.js` 상식 데이터)
- `node build.js` — `src/`를 합쳐 `public/index.html`(단일 파일) 생성. 수정 후 반드시 실행.
- `server.js` — 정적 파일 + 방별 상태 중계(SSE). 게임 판정은 **방장의 브라우저**가 한다.
- `test/gen_test.js` — 39종 × 두 난이도 문제 생성기·판정기 검증 (`npm test`)
- 개발용: 주소 끝에 `#t=hap,lights`처럼 붙이면 그 게임만 나온다

## 알아둘 점
- 방장 브라우저가 채점하므로, 개발자 도구를 다룰 줄 아는 사람은 답을 엿볼 수 있다. 친구끼리 하는 용도.
- 방장이 창을 닫으면 그 판은 끝난다. 진행 중인 판에는 새로 못 들어오고, 끝난 뒤 "한 판 더"부터 참가된다.
- claude.ai 아티팩트 안에서 열면 서버 대신 claude.ai의 room 기능으로 연결된다.
