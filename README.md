# 🧠 두뇌 배틀

수학·상식·퍼즐·두뇌·심리 **16종 미니게임**을 친구들과 겨루는 실시간 웹게임. 베팅 없이 순수하게 문제를 맞혀서 점수를 얻는다. 라운드 1등은 상대에게 방해 카드(안개·거울·시간 단축·점수 강탈)를 쓴다.

| 분류 | 게임 |
|---|---|
| 수학 | 🧮 숫자 조합 · ⚡ 암산 질주 · 🔢 수열 추리 |
| 상식 | 📏 어림 감각 · 🧠 상식 번개 · 📜 역사 줄 세우기 · 🔤 초성 퀴즈 |
| 퍼즐 | 🕵️ 범인 추리 · 🔐 금고 털기(숫자야구) |
| 두뇌 | 🟦 패턴 기억 · 📟 숫자 기억 · 🎨 색깔 함정 |
| 심리 | 🎯 2/3 게임 · ⚖️ 소수결 · 🥷 최저 유일수 · 🗡️ 배신의 금고 |

## 점수
정답이면 `50 + 속도 보너스(최대 70)`, 라운드 최속 정답 +25, 오답·시간 초과 0점. 심리전 4종은 규칙이 다르다(게임 안에 설명 표시).

## 실행
```
npm start        # http://localhost:3000  (의존성 없음, Node 18+)
```
같은 와이파이의 친구는 `http://내IP:3000`으로 접속한다.

## 친구와 온라인으로 하려면 (서버 배포)
멀티플레이에는 **서버가 켜진 주소**가 필요하다 (GitHub Pages는 정적 호스팅이라 서버를 못 돌린다).
- **Railway / Render / Fly.io**: 이 저장소를 연결하면 `npm start`가 자동 실행된다. 환경변수 `PORT`만 쓴다.
- 배포된 주소를 친구에게 보내면 끝. 홈 화면에서 방을 만들고, 친구는 "열린 방"에서 누르거나 4자리 코드를 입력한다.
- 서버 없이 열면(GitHub Pages 등) **혼자 연습**만 가능하다.

## 구조
- `src/` — 게임 소스 (`gen.js` 문제 생성기, `app.js` 화면·게임 진행, `rt.js` 연결 계층, `data.js` 상식 데이터)
- `node build.js` — `src/`를 합쳐 `public/index.html`(단일 파일) 생성. 수정 후 반드시 실행.
- `server.js` — 정적 파일 + 방별 상태 중계(SSE). 게임 판정은 **방장의 브라우저**가 한다.
- `test/gen_test.js` — 문제 생성기 검증 (`npm test`)

## 알아둘 점
- 방장 브라우저가 채점하므로, 개발자 도구를 다룰 줄 아는 사람은 답을 엿볼 수 있다. 친구끼리 하는 용도.
- 방장이 창을 닫으면 그 판은 끝난다. 진행 중인 판에는 새로 못 들어오고, 끝난 뒤 "한 판 더"부터 참가된다.
- claude.ai 아티팩트 안에서 열면 서버 대신 claude.ai의 room 기능으로 연결된다.
