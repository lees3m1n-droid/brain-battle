# 🧠 두뇌 배틀

**기기 하나로 여럿이 둘러앉아 하는** 두뇌·파티 게임. 수학·상식·퍼즐·두뇌·심리·파티 **56종** (최대 4명). 같은 게임도 숫자와 상황이 매번 새로 만들어진다. 서버 없이 `public/index.html` 하나로 돌아간다.

## 노는 방법
처음 화면에서 인원(혼자~4명), 모드, 라운드 수, 게임 종류를 고르고 시작. 참가자는 빨강·파랑·초록·노랑 색으로 구분한다. 2명 이상이면 라운드의 절반 정도가 파티 게임이다.

| 방식 | 설명 |
|---|---|
| 📱 **차례 게임** | 기기를 돌려 가며 한 명씩 자기 문제를 푼다. 문제는 사람마다 새로 만들어져서 앞사람 답을 봐도 소용없다. 풀고 나면 바로 정답과 점수를 보여 준다 |
| 🤫 **심리전** | 한 명씩 몰래 고른 뒤 마지막에 한꺼번에 공개 |
| 🫶 **파티** | 기기를 가운데 두고 다같이. 화면 위아래에 각자 색 버튼이 있다 (4명이면 맞은편 두 사람 버튼은 뒤집혀 있다). 버저를 누른 뒤 답할 시간은 몇 초뿐이다 |

## 두 가지 모드
- ⏱ **타임어택** — 제한시간 안에, 빠를수록 고득점 (`50 + 속도 보너스 최대 70`, 라운드 최속 정답 +25)
- ♾️ **무제한** — 어려운 문제, 시간 제한 없음. 정답 100점. 🏳️ 포기 가능. 속도만 겨루는 게임은 빠진다

- **결! 합!** 은 더 지니어스 규칙대로 판이 끝날 때까지 한다: 합을 찾으면 버저 → 3장 선택(+30 / 틀리면 −10), 더 없다고 생각하면 「결!」(맞으면 +60으로 판 종료, 틀리면 −20). 무제한 모드는 12장 판.
- 상식은 246문제. 그중 113문제는 어려운 문제로, 무제한 모드에서는 어려운 문제만, 타임어택에서는 절반 정도 섞여 나온다.
- 퍼즐은 자동 생성되고 답이 하나인지 검사한다. 무제한(어려움)에서는 4자리 숫자야구, 6×6 스도쿠, 7×7 노노그램, 12개 동전 등으로 커진다.
- 심리전·파티는 매 판 조건이 바뀐다 (평균 배율, 소수결 주제, 369 규칙과 시작 숫자, 업다운 범위, 타이밍 목표 시간, 라이어 주제…). 라이어 게임 무제한 모드는 라이어도 자기가 라이어인 줄 모르는 「바보 라이어」.
- 인원 제한: 심리전·버저 퀴즈·반응속도·업다운·369·시한폭탄·연타 대결은 2명부터, 라이어 게임·눈치 게임·이심전심은 3명부터.

## 실행
`public/index.html`을 브라우저로 열면 끝. GitHub Pages에 올리면 주소 하나로 어디서든 열 수 있다 (`.github/workflows/pages.yml`).

## 구조
- `src/` — `gen.js`·`gen2.js` 문제 생성·판정, `core.js` 채점·심리전 결과, `app.js` 진행·화면, `party.js` 파티 게임, `ui1.js`·`ui2.js` 게임 화면, `data.js`·`data2.js`·`data3.js`(어려운 상식) 데이터
- `node build.js` — `src/`를 합쳐 `public/index.html`(단일 파일) 생성. 수정 후 반드시 실행
- `npm test` — 문제 생성기·판정기 검증
- 개발용: 주소 끝에 `#t=hap,liarw`처럼 붙이면 그 게임만 나온다
